# Edu-Time-Date-Calculate

이 프로젝트는 아이들이 시간과 날짜 개념을 쉽게 이해하고 계산할 수 있도록 돕기 위해 만들어진 교육용 시간 달력 프로그램입니다. 오픈 소스 MVP(Minimum Viable Product)로 개발되었습니다.

## 프로젝트 개요

아이들의 눈높이에 맞춰 직관적이고 시각적인 방식으로 시간의 흐름과 날짜 계산을 학습할 수 있도록 설계되었습니다.

## 기술 스택

- Svelte
- SvelteKit

## 시작하기

### 개발 환경 설정

프로젝트를 로컬에서 실행하려면 다음 단계를 따르세요.

1.  **의존성 설치**:
    ```bash
    pnpm install
    ```
2.  **개발 서버 실행**:
    ```bash
    pnpm run dev
    ```
    또는
    ```bash
    pnpm run dev -- --open
    ```
    (개발 서버를 시작하고 새 브라우저 탭에서 앱을 엽니다.)

### 빌드

프로덕션 환경용으로 앱을 빌드하려면:

```bash
pnpm run build
```

빌드된 앱을 미리 보려면 `pnpm run preview`를 실행합니다.

> 앱을 배포하려면 대상 환경에 맞는 [어댑터](https://svelte.dev/docs/kit/adapters)를 설치해야 할 수 있습니다.
